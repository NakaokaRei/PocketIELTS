Pokelts is a self-study app for English learners preparing for General Training. It helps learners practise individual skills, understand mistakes and track progress. Band and CEFR estimates are for personal study.

Optional online features: Connect an existing ChatGPT account in Settings for new exercises, contextual explanations and feedback. From Home, choose a skill and a section to practise. Generated listening audio, generated images and realtime Speaking use a separate personal OpenAI API key in Settings. Realtime Speaking also requires microphone permission. OpenAI handles external sign-in. The app has no developer-operated account registration. Settings provides sign-out, key removal and a learning-data reset. Answers, recordings and conversations are private; there is no public feed or messaging between users.

Services: OpenAI provides authentication and AI features. Apple provides optional private iCloud sync through CloudKit and on-device speech recognition for recorded answers. The app is free with no in-app purchases or subscriptions. Personal API usage is billed separately by OpenAI.

Regions: Bundled exercises and core practice flows are the same across distribution regions. The interface is localized. Online features depend on provider availability and account access.

Rights: This is an independent educational practice app. It does not issue official exam results or qualifications. Bundled third-party fonts (Nunito and Zen Maru Gothic) include their redistribution licences.
