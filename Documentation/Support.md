# Pokelts（ポケルツ） Support / サポート

**Email / メール**　[rei.n@me.com](mailto:rei.n@me.com)

For help, send your device model, OS and app version, the screen or exercise involved and what happened. For a public bug report, use [GitHub Issues](https://github.com/NakaokaRei/PocketIELTS/issues). Send privacy requests by email. Please leave API keys, credentials, recordings and personal study material out of reports.

不具合については、機種、OSとアプリのバージョン、発生した画面・パート、操作手順をお知らせください。公開可能な不具合はGitHub Issuesでも受け付けています。プライバシーに関するご相談はメールをご利用ください。APIキー、認証情報、録音や個人的な回答は送らないでください。

| Question / ご質問 | Answer / ご案内 |
|---|---|
| Can I practise offline? / オフラインで使えますか？ | Bundled material and saved exercises are available offline. New AI requests require a connection. 収録教材と保存した問題はオフラインで利用できます。AIへの新規リクエストには通信が必要です。 |
| Why is an API key requested? / APIキーが必要なのはなぜですか？ | Generated audio, optional generated images and realtime speaking use your OpenAI API account and can incur charges separately from ChatGPT. 音声生成、任意の画像生成、リアルタイム英会話はOpenAI APIを使用し、ChatGPTとは別に利用料が発生します。 |
| How do I remove study data? / 学習データを消すには？ | Open Settings and choose Reset all learning data. Keep iCloud sync enabled and online to sync the deletion. 設定の学習データのリセットを使用し、iCloud側にも反映するには同期をオンにしてオンラインで完了を待ってください。 |
